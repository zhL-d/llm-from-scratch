Setting Up A Node Development Environment

In order to get the best possible development experience, and if you don’t have node yet installed: I advise you to go the nodejs.org website and install the latest version of node:

Please make sure not to use the long-term support version (LTS), but the latest version instead. We will be using node for frontend tooling purposes and for running our development server, and for that specific purpose, you will usually run into fewer issues if you use the latest version.

But, if you already have node installed (any version almost), there is a much better way to upgrade your node version than to run an installer - why you might not be able to in a company computer.

To avoid running into any issues with constant reinstallations of node, I suggest the following: instead of overwriting your current version of node with the latest one, let's use a simple command line tool that easily allows switching node versions.

Why use a command line node versioning tool?

Using a tool like that has several advantages:

It’s very useful to be able to quickly change node versions if for example, we have multiple projects to maintain on the same machine, and each project needs different versions of node.

with such tool, upgrading to newer versions of node in the future will be much easier – we will not have to run an installer in your machine again

So first before starting, let’s make sure that you have at least some version of node installed on your machine.

Installing The Nave Command Line Tool

If you are using a Linux or Mac environment, then let’s go ahead and install the nave command line tool, which is available on npm:

The command to install this tool is:

npm install -g nave

Please remember that you might have to add “sudo” at the beginning of some of the commands in this book if you are not an administrator on this machine.

If you are on Windows, you can instead install the nvm-windows tool that gives you equivalent functionality:

With a node version changing tool in place, lets then install a given version of node. For example, lets bring the version 7.9.0 to our development machine, and start a shell with it:

> nave use 7.9.0 #################################################### 100.0% installed from binary > node -v v7.9.0

If using nvm-windows, the command would then be:

nvm use 7.9.0

In both cases the result would be the same, we have just started a new shell with the chosen version of on the path.

if you are on Windows and looking for a Bash shell that does not take administration privileges to install, have a look at Git Bash

We will now be able in the future to easily upgrade versions – that's a great start! Now let’s continue laying the foundation for our development environment.

Npm is the official node package manager, but we will be using a different alternative. Let’s learn why we would want to use the Facebook Yarn Package Manager instead.

Why Use The Yarn Package Manager instead of NPM?

While using npm, you might notice that sometimes you run into the following situations:

You run npm install, and you get an error on the terminal, then you run the same command again and the error is gone. This is sometimes caused by proxies and network issues, but a lot of times it's not the case

you have a project running on on your machine in one folder, but you checkout the code to another folder and install it there, and it's somehow not working there due to dependencies issues

your production or staging environment build fails due to dependency related errors that you don’t have on your local machine

Another developer working on the same project is running into dependencies issues but on your machine it's working great: or the other way around 🙂

All these issues are related to a couple of inherent problems of the way that the npm package manager works by default.

The biggest difference between Yarn and NPM

Npm uses semantic versioning, which means that we will take upon installation a dependency version of a library that is in a certain range of versions.

While on paper this sounds like a good idea to enable getting continuous patch updates of dependencies, in practice, it doesn't work as well as one could think.

Facebook used to run into these issues too in their internal builds, and so they have created an alternative package manager that they have first tested extensively internally and then open sourced: The Yarn Package Manager.

So let’s try it out and learn the advantages along the way. To install Yarn, let’s do the following:

npm install -g yarn

Yes I know, we used npm LOL 😊 I will likely be one of the last times though.

So we now have installed Yarn globally. Let's now use it as much as possible, because it will unlike npm “freeze” the dependency tree, and ensure that the code that runs in production and in other developers machine is the exact same code that runs on your machine as well.

So how does Yarn Work Then?

It's actually quite simple, upon project installation Yarn will freeze the dependencies by making note of what libraries were installed in a file which is called yarn.lock .

So to install a file and generate a lock file, we simply have to run the following command in the same directory as your package.json is:

yarn

This does the same as an an npm install, meaning:

it will inspect the package.json and calculate a tree of library dependencies

it will download all project dependencies and write them under the node_modules folder

This is so far what npm does as well, so why use Yarn instead?

Two immediate Advantages of Yarn

At this point, if nothing else yarn would really be bringing us two very important advantages:

Yarn is much faster than npm, especially for projects with a lot of dependencies, like for example projects that are scaffolded using the Angular CLI

Using Yarn you will not run anymore into that very frequent scenario of having to either run npm install multiple times until it completes (with a couple of cache cleans in the middle), or having to delete node_modules and reinstall

The Biggest Advantage Of Yarn

The improved speed and reliability alone would already make Yarn a better alternative. But those might not be the biggest advantage. The biggest thing about Yarn is that during the installation it will keep track about all the dependencies that it has installed.

Yarn will write the exact version numbers of each library that is has downloaded and it will put those in a text file, called a lock file. You will see it right next to your package.json once the installation completes.

A couple of things about the yarn.lock file

This is just a plain text file, here are some important points about it:

we should not edit it manually, only Yarn should modify its file in result of a command that we execute in the command line

we need to commit this file to source control

So what is the big advantage of having a lock file, and of the Yarn approach in general?

Committing the file ensures that any other developer using the same code base will have the same exact dependencies then you. This is really convenient because problems due to library differences are much more prevalent than one could think.

And what about when we commit something and the integration build fails due to differences between libraries in the continuous server machine and our local machine, how are we going to debug that?

Imagine the headache that such situation could cause, because you probably don’t have access to the file system of the integration server.

Yarn advantages in a Nutshell

Keeping a lock file and using the same exact dependency tree everywhere avoids so many time-consuming problems. In a Nutshell, and to summarize the advantages of Yarn we can say that:

Yarn gives us faster, more reliable and most of all reproducible builds, meaning that we will never have to debug issues due to having different libraries on different machines

The Migration Period

The fifth and sixth centuries are often called the “Migration Period,” because peoples from outside the Roman Empire migrated into the former Roman provinces and established small, independent kingdoms. Among most of these groups, it was customary to bury the dead accompanied by personal possessions. These objects (including glass) provided 18th- and 19th-century antiquarians with raw material for the study of early medieval culture.

The study of early medieval glass is essentially the study of drinking vessels. Although most of the best examples of complete vessels have been recovered from graves, the occurrence of fragments of identical types of glass in settlements shows that the objects buried with the dead were the same as those used by the living. Some of the earliest glasses resemble those produced in late Roman times. The forerunners of claw beakers, for example, were made in Roman workshops in the third and fourth centuries.

The Vikings and Their Glass

The years between 800 and 1000 are the “Age of the Vikings,” referencing the collective name for many of the inhabitants of medieval Scandinavia. Eyewitnesses recorded with horror the bloodthirsty raids of Vikings in search of booty. But this was not the whole story. Sailing their long ships, the Vikings planted settlements in Iceland, Greenland, and even in Newfoundland in Canada. Meanwhile, Viking merchants traveled along the Volga River to the Black Sea, and Viking mercenaries formed the Byzantine emperor’s Varangian Guard.

At home in Scandinavia, and in northwestern Germany, the Viking merchants created trading centers, where archeologists have recovered artifacts from many parts of Europe and the Middle East, including glass vessels from western Europe. Indeed, some of the best preserved glasses of this period have been discovered in Viking graves.

The Later Middle Ages

Finds from archeological excavations show that most of the late medieval vessels used at home were intended for serving and consuming beverages. Paintings of the Last Supper, the Wedding at Cana, and Herod’s Feast depict tables set with one or more bottles of wine and a larger number of beakers or goblets — although not enough for everyone. Glasses were shared, as were knives and other utensils.

The beakers came in a variety of shapes and sizes. The smaller vessels often had barrel-shaped bodies, while the larger examples had tall, tapering sides. The ornament sometimes consisted of horizontal rows of “prunts” (small blobs of glass attached to the side of the beaker).

In southern Germany, Switzerland, and parts of Italy, the best late medieval glass was either colorless or almost colorless, and was the forerunner of Venetian cristallo of the Renaissance. This colorless glass was made by carefully selecting the raw materials and by adding a small amount of manganese oxide, a mineral traditionally known as “glassmakers’ soap” because of the way it removed the colors caused by impurities.

Forest Glass

Most vessels produced in the later Middle Ages in northern Germany, the Low Countries, and central Europe were made of transparent green forest glass, so-called because it was produced in small glasshouses located in forests, which provided a convenient source of fuel. Its color was caused by the presence of impurities, mainly iron oxide, in the raw materials.

A late variety of the prunted beaker was a vessel known as a Krautstrunk (German for “cabbage stalk”), so named because the ornament consists of large blobs projecting from the side of the vessel like the scars on a cabbage stalk after the leaves have been removed.

Saints, with divine assistance, were believed to perform miracles. Items brought into contact with relics (such as oil from lamps burning above a saint’s shrine) were also venerated, and pilgrims took them home as evidence of their devotion. By the late Middle Ages, the cult of relics attracted pilgrims from all walks of life. In the 12th and the 13th centuries, Latin translations of books written by ancient Greek and Muslim scientists began to circulate in Europe. Science and medicine were two fields that benefitted directly from new knowledge gained through improvements in glassmaking. Many scientific experiments depended on glass apparatus that were transparent and did not contaminate their contents by corroding.

No apparatus played a more important role in medieval experiments than the still, which was used for preparing acids used in alchemy (medieval science) and for distilling alcohol. In medicine, physicians used glass flasks for uroscopy: using the color of urine to diagnose disease.

The invention of reading glasses was a direct result of experiments with lenses. Spectacles, consisting of a pair of lenses assembled for wearing in front of the eyes, were invented in Italy. By Josh Snyder

Editor’s note – this is part one in a series on the Far Cry franchise. To read part two, click here.

Video game franchises are an odd thing – consumers often demand innovation and change, but our spending habits suggest that we prefer sequels and familiar worlds. Finding this balance, where a developer learns from past mistakes and changes aspects of their game while trying to keep that core experience intact, can lead to some amazing experiences, and some not-so-good ones. Dead Space 2 improved the combat and character development, but kept the eerie, tense atmosphere from the original. And then there’s Metroid: Other M, which completely lost the thread while trying to be something new, and in the process lost the heart and soul of Metroid.

As a way to avoid this, some developers have started to create new franchise entries that are spiritual successors instead of direct sequels. BioShock: Infinite is a perfect example – it maintains many of the same core mechanics and style of the original BioShock, but it is not a direct sequel in terms of story. This approach works for some franchises, and when examining these games, it’s fascinating to see what aspects developers keep, what they get rid of, and what new gameplay mechanics emerge in their place.

Which brings us to one of the most controversial, intriguing and popular franchises of the last generation – Far Cry. What started out as a showpiece for developer Crytek has morphed into one of the staples of the FPS genre. This popularity peaked with the latest entry, Far Cry 3. On its own, it is a fun first-person shooter (FPS) set in an expansive open world, even if it has its flaws. However, when judged as a follow-up to its predecessor Far Cry 2, flaws in the formula begin to emerge, and the game suddenly feels tone-deaf and out of place. Which begs the question – what happened to Far Cry 3? What sorts of changes led to the final product, which seems drastically different from any previous game in the franchise?

With a new entry in the series right around the corner, understanding what went right with Far Cry 2, and what went wrong with Far Cry 3 could help when experiencing Far Cry 4. Far Cry is an important franchise, and though it has its flaws, it is one that demands to be taken seriously – it was one of the first franchises to be a true genre-hybrid (open-world, FPS), and therefore its impact cannot be understated.

What Defines Far Cry?

Trying to define the core Far Cry experience can be a bit tricky, as the franchise has had two developers over its lifespan. The original Far Cry was developed by Crytek and published by Ubisoft. Shortly after the original took off in popularity, Ubisoft took complete control of the franchise, re-releasing the original and adding some strange, sci-fi elements to the game. Due to limitations on the home consoles at the time, the open-world aspect that PC gamers loved was dropped, resulting in a game decidedly unlike the original Far Cry. But with the release of Far Cry 2, it was clear the Ubisoft was using these console-ports to keep the franchise in the public mind, while they worked on the second proper entry.

Ubisoft has toyed with open-world level design in some of their recent franchises, with varying degrees of success. In their typical vision of the open-world, the player manipulates the world for their own ends, such as being able to hide in plain site in Assassins Creed, or hacking the surroundings to block pursuers and escape, such as Watch_Dogs. The world is meant to be used by the player at will, with very little consequence. It’s a selfish approach that works in a medium in which the player is rarely punished for crossing the line and using the world to meet their ends.

The Far Cry franchise is a bit unique in this way. The player is still encouraged to use the elements of the world to complete their objective, however, the world always has an impact on the player. In the original Far Cry, the world acts as sort of a prison – the player cannot leave this place until completing the quest. For all the freedom the game allows, the player is still trapped, caged in a world that is just as quick to lash out at them as the player is to it. This creates a dependent-relationship between the player and the open-world which isn’t seen too often – the player needs the world to complete their objective, but the world is not meant to be a toy the player can use endlessly with no care.

The open-world-player relationship is key to the Far Cry experience, but it isn’t the only pillar of the franchise. The story and characters have always been closely linked, to the point where they can be viewed as a single element. Captured characters needing rescue, or characters needing tracked down and eliminated often compose the majority of the story, and that’s fine – this simplistic approach allows Ubisoft to weave in complex themes that carry over between the story and the open-world, tying both elements together. The final piece, and the one Ubisoft has the most flexibility with, is gameplay – the element that allows the player to navigate and utilize the open-world, and to work toward freeing or killing the target character, whichever the story demands.

Since it was their first entry in the series, it stands to reason that Far Cry 2 would serve as the basis for which future Far Cry games are based on, at least ones developed by Ubisoft. To begin to understand this franchise, we need to analyze Far Cry 2, and see how this formula was implemented.

Into the Heart of Darkness

It’s not uncommon for developers to base the story of their game off of a famous piece of literature, and it’s not even uncommon for that piece of literature to be Heart of Darkness, by Joseph Conrad. Ubisoft does not hide the references to Heart of Darkness, and therefore it stands to reason that the themes Ubisoft wants the player to pick up on are ones of isolation, fear and paranoia, and to put them in a world in which the player is not wanted, a world that will destroy the player’s mind and body.

Far Cry 2 successfully achieves these themes and feelings, and in understanding how it does so, we can better appreciate what Ubisoft has on their hands with the Far Cry franchise.

The Open-World

The single most important element of Far Cry 2 is the world in which the game is set. Taking place in a failed Central-African state, the player navigates a myriad of terrains, such as swamp, mountains, savannas and jungles. But the aesthetics of the land are not the centerpiece – the turmoil and brutality the world fosters are the main attractions.

To make sure the player understands this, the game begins with the player character, who is chosen from a list of ex-military guns-for-hire types, being driven from the airfield to their hotel. This Half-Life-inspired opening allows the player to sit back and enjoy the ride, take in the sights, while the cab driver waxes poetic about the current state of affairs. The player cannot directly control this scene, but can look around, and what they see sets the tone for the next 50 hours of gameplay. The roads the cab takes are hardly roads at all, with debris from washed-out bridges scattered across the land. The cab takes a noticeable dive when crossing what was once a smooth, well-kept road, and the cab driver casually remarks on how no more planes will be entering or leaving the country for a long time – better get used to this, this is your home now. Occasionally, there will be an open-vista the player can take in, but there are just enough run-down and abandoned shacks dotting the landscape to remind the player that this land is home to death, decay and destruction, and the locals who remain, who watch as you pass them with disdain in their eyes, all carry assault rifles and large knives. The player gets the sense that those weapons are not used for hunting.

After being stopped at a checkpoint and briefly harassed, the cab driver gets the player to the hotel when the final kick to the gut happens – the player character doubles over in pain, the screen a blurred mess, his heart throbbing, pounding, as the cab driver turns and remarks on how ill he looks.

Less than 30 minutes in this country, and it has already given the player its first gift – malaria.

After a brief tutorial, the player gets dropped into the world, free to explore or take on any number of tasks. But navigating the world is tricky – tall, imposing mountains funnel players into enemy-controlled territory, and the player must try to sneak past, or fight their way through 20 armed soldiers. Planning a route to the next objective is advised, but even this is time-consuming and complex – the map must always be viewed in real-time, meaning the game never pauses to allow the player ample time to view the map. In addition, only two views of the map are presented – the entire map can be viewed all at once (this view lacks crucial details, such as the location of enemy outposts or safe houses) while the second view zooms in considerably, showing those important landmarks (this view only shows the section of the map the player is standing in).The entire map is made of a 3×3 grid, so the player must learn to memorize what is in the adjacent squares at all times. Again, the world is technically open, but trying to get to the bottom-right square from the bottom-center square isn’t always as easy as heading east in a straight line – just as one may think they are about to reach their destination, the road turns north, and a giant wall blocks access to the goal, which means the player must now successfully bypass any number of enemy outposts, or once again, fight through them all.

To the modern gamer, many of these obstacles would just be avoided by fast travelling to the desired location. But again, Far Cry 2 forces the player into foregoing convenience. Technically, there is a fast travel system, but it’s limited – the player must make it to one of five bus stations – (one in each corner of the map, and one in the center), meaning that the fast travel system only works for a little over half of the map, while the other half must be accessed the good old fashion way. But even if the player already resides in one of the squares with a bus station, getting to its exact location is never guaranteed to be simple. Countless enemy patrols keep an eye on the roads which lead to the bus stations, and at the slightest hint of trouble, those patrols, with their mounted machine guns or grenade launchers, hunt the player down mercilessly. It’s clear that Ubisoft wants the player to experience every square meter of the world, while constantly reminding them that danger lurks around every corner.

To help ease the burden of travel, players can hop into a car and drive through the savanna, doing their best to outrun the countless enemies that are no doubt in pursuit. But again, this world is not some futuristic sci-fi wonderland – these vehicles are old to begin with, and are untrustworthy at best. They will break down, forcing the player to repair them while dodging bullets and hopefully not getting picked-off by a rocket launcher. And if the player defends themselves, they better hope they have a new gun, as guns degrade on the player over time, and jam consistently if not replaced. These mechanics contribute to a world that wants to constantly remind the player that they are not welcomed, that the world is hostile, in disrepair and possibly past the point of saving, if that ever was the goal.

Safe houses dot the environment and can be upgraded to provide the player with ammo, grenades, health and a new car. Safe houses, at their base level, allow the player to save the game by resting, which means that there will always be some passage of time. Far Cry 2 has a day/night cycle, and being caught out in the wild at night is never a good idea. Many times these safe houses are a welcomed sight, if only to advance the clock to six in the morning, so the player can actually see where they are being shot from. And once they are upgraded, they become one of the few reliable sources of supplies in the world.

Without even touching the story or the characters, Far Cry 2 has told the player that this world is dangerous, and even the most simplistic of actions will be a struggle. The themes of fear, paranoia and struggle are woven into the very fabric of the world – the perfect setting for a game that tries to push the player’s limits.

The Story/Characters

After recovering from the first malaria outbreak, and escaping from an attack on the hotel the player called home, the game pauses, and a simple message appears on the screen: find and kill the Jackal. That’s the entire plot of Far Cry 2 – nothing more, nothing less.

The Jackal is an arms dealer, one who has been supplying both sides of the war. Eliminating him will not guarantee an end to the conflict, but the thought early on is that it will certainly make it less bloody. But the point of Far Cry 2 is to show the player firsthand how vicious and cruel this world is, even if there were no guns or explosives. Ubisoft’s choice to have such a simple plot allows for the characters and events to be the ones to drive the themes of colonialism and never-ending war, freeing Ubisoft up from having to worry about throwing plot twists and turns at the player simply for the sake of keeping them entertained. We have our goal, and it’s all we need.

After the completion of a few story missions, it seems that Ubisoft doesn’t care about establishing characters or giving them motivation in this conflict. The player bounces from one nameless war mongerer to the next, happily taking diamonds, the currency of the game, and heads out to complete a basic mission. Go to point A, steal something, take it to point B, blow everything up, and call it a day. Complicating matters is that, for every story mission, there is an alternate way of completing it, and these alternate paths are handled by a group of people called “Buddies” – fellow mercs who work alongside you to track the Jackal down. These characters have faces and names, but they matter as much as the warlords; not at all.

But what seems to be lazy writing at first slowly emerges as a conscious choice. Buddies helping the player out on a mission can succumb to their wounds, and the only change is that the buddy who was listed second on the list is now the player’s primary buddy. Warlords are assassinated and replaced, and the only thing that changes is the amount of diamonds the player collects at the start of each mission. It isn’t until the player pays attention to what these simple, linear missions are actually having them do that the whole point of the game is made clear.

Bomb a clinic. Assassinate a politician begging for peace. Destroy sources of fresh water. Bomb and destroy stockpiles of medicine. Just bomb and destroy everything. Infrastructure, crops, people – destroy it all.

The Jackal is not the real enemy here. Killing him will do nothing. This country will tear itself apart, and in the haste of finding just one man to take out, the player ensures this ultimate demise, every step of the way. The main story missions may seem like uninspired, linear fetch quests, but the implication of these is that this world is unfair, that the player is not there to rescue it. Taking out one faction’s food supply, bombing the airfield of the other’s, it will change nothing. Have a buddy die in combat, and another will take their place. Mercs are a dime-a-dozen, including the player. Far Cry 2 is a far cry (excuse the pun) from the Halos and Elder Scrolls of the world, in which the player is this grand hero, and only they can save the world.

This brutality meshes perfectly with the harsh open-world – they both play off of each other and bring the player to a place few games dare tread. But it’s in the final piece of the puzzle, the gameplay, where Ubisoft ties it all together perfectly.

The Gameplay

One of the problems with the FPS genre is that, typically, the player controls one super soldier, one individual who can turn the tides of war all by themselves. Far Cry 2 doesn’t set out to solve this problem – after all, the main force behind many of the missions that cripple the factions or cause general chaos is the player character, but never at any point will the player feel invincible or stronger than their surroundings.

To start, the player gets malaria. Medicine is needed to stave off death, and the game is kind enough to remind you when you need to take the medicine – the screen turns fuzzy, and a button prompt appears in the bottom-left corner. Taking medicine or course takes time – opening up the pill bottle, pouring one pill and swallowing it – all of that is animated. Which means the player better hope a malaria attack doesn’t occur during combat, or else the player will be vulnerable just long enough for an enemy to run up and get a point-blank shot off with the shotgun. Malaria attacks occur about once everything 30 minutes – just frequently enough to make the player question if they should wait before taking out an enemy outpost, or if they have enough time to risk it.

Taking medicine is not the only action that happens in real-time in Far Cry 2 – many other gameplay elements take the player out of combat, ones that in most games are handled in a menu or instantaneously. As previously mentioned, reading the map is done in real-time, and the player character holds it out in front of them like a tourist, in other words, in a way that takes up most of the screen. When the player runs with the map out it provides some relief, but the fact that it’s there at all is enough to agitate gamers who are used to the map being accessible at their leisure while the rest of the game world pauses and waits. Vehicles that take damage can be repaired, which means getting out of the car, popping the hood, and using a wrench to fix the engine. It’s not necessarily realistic, but again it takes time, time that you are vulnerable to attack. The enemies in Far Cry 2 do not run straight at the player in one huge wave – many of them hide in the bush, and will wait for the player to turn their back before firing. And with no radar, the only way the player knows they are safe to repair their vehicle is if they take the time to make sure every enemy has been disposed of.

If the player neglects this, and finds themselves on the bad end of a confrontation, then they will have to experience the most cruel aspect of the real-time gameplay – healing. The health meter is split into five chunks, and once one is depleted, the only way to refill it is to consume a health syringe. That is, until the player finds themselves with just a tad of health left in the final section. At that point, the player must hold down the left-bumper button and watch as the player character stabilizes their health by either re-setting a dislocated joint, pulling a bullet out of wound with a pair of pliers, or bandaging a nasty cut. This won’t refill the player’s health – just the first two sections, but it then allows them to use a health syringe.

If the entire healing action can be completed, then the player must hope that their guns are in good enough condition to fire. If not, they will jam, and the player will have to mash the left-bumper button to un-jam the weapon. Guns, depending on whether or not they have been upgraded, will degrade quickly. Even if upgrades have been purchased, weapons will still jam. Of course, the only time the player will learn that a gun has deteriorated to that point will be during combat. Yet another way in which the game reminds the player that they are weak.

Buying weapons with diamonds means going to one of a few gun stores dotted around the world. At these gun stores, the player can also restock on ammo and acquire brand new guns that won’t jam. The problem is that these items are expensive, and there are only a few ways to get diamonds – through the main story, through assassination side-missions and by briefcases located out in the wild.

There are over 200 briefcases to find, and they offer anywhere between one and three diamonds. This may not seem like a lot, but it can add up quickly, and is necessary for acquiring many of the late-game upgrades. The game provides the player with a diamond tracker, which will blink if the player is close to a diamond. This means that, during the quiet moments, players will blindly run through the jungle, eyes focused on a green blinking light in the bottom-right corner, hoping to stumble onto another small treasure so they can buy a durability upgrade for their assault rifle.

Nothing in this game is simple, and that’s the point – with a harsh overworld and brutal story, the gameplay has to match. Ubisoft tweaked and balanced the gameplay specifically to fit in with the themes the other two areas of the game explore. Far Cry 2 would feel wrong, out of step, if in this hellish world the player was a Duke Nukem-type, mowing down enemies without a care in the world.

Emerging out of the Dark

Despite all of this, Far Cry 2 has its share of flaws. In some ways the game feels rushed, a typical problem with Ubisoft games. And in an attempt to convey to the player that war never ends, enemies respawn at outposts the second the location is outside of the player’s draw distance, which is a polite way of saying that enemies respawn way too often. But the point is, because Ubisoft fine-tuned the three core pillars of Far Cry 2 to work off of and in-sync with each other, these flaws are easily overlooked. Far Cry 2 demonstrates the sheer potential of this franchise.

Which is why Far Cry is such a strange franchise – not only does Far Cry 3 seemingly abandon the successful elements of Far Cry 2, but the three core pillars are in no way working off the other. At the end of the day, the answers to what went wrong with such a highly touted game might be found here, in central Africa, amidst a burning pile of false hope, lies, winners and losers. In Far Cry 2, everything burns.
